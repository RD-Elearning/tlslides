# Slide block index

Choose the category from the relationship in the content, then the block. Dated → `timeline`; ordered but undated → `process`; options against each other → `comparison`; numbers that need axes → `chart`; one to four headline numbers → `metric`.

Scope rules:
- `element`: one atom. Combine several on a slide or inside a container.
- `group`: a self-contained unit. One per region; may sit inside `tls.l.card` or `tls.l.section`.
- `slide`: fills the whole content area. One per slide, alone in the main region. Never nest it.

Line format: `type · category · scope · item range — what the viewer sees`. Ask for the detail digest of the shortlisted types before filling props.
